PRIMERA ENTREGA MÓDULO 2 - CURSO PYTHON 

CONSIGNA PROPUESTA: Escribir un programa que administre sensores IOT en una planta de cemento, el cual permita al usuario crear la cantidad de sensores que desee, borrarlos,      agregar nuevos, modificar sus parámetros, consultar su medición actual y valores anteriores.
El usuario debe tener la posibilidad de setear cuantas veces al día quiere que el programa adquiera los datos de los sensores, y en qué horarios.
